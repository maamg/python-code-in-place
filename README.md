# Python Code in Place

Exercises from the Stanford Code in Place learning stage. The files show structured practice with functions, loops, conditionals, graphics and small problem-solving tasks.

The code is presented at repository root for quick review. Course scaffolding and exploratory files are retained and should be read as learning evidence, not as a completed software product.

## Representative exercises

`baby_snakes.py`, `centered_square.py`, `khansole.py`, `stepup.py`, `weight_on_mars.py` and the diagnostic exercises.
